1. 设计概述
本方案为智能体对话界面设计，支持多模型切换、流式输出、参数调节等核心功能。整体采用暗色主题 + 毛玻璃质感，三栏式布局，强调沉浸式对话体验。

2. 页面布局
页面分为三个区域：

顶部导航栏：品牌标识、当前模型选择、新建对话、设置
左侧会话栏：历史对话列表，支持新建
中间对话区：消息展示 + 流式输出 + 输入框
右侧控制面板：模型切换、参数调节（可收起）
3. 组件说明
3.1 顶部导航栏
左侧放置品牌 Logo
中间显示当前模型名称，带下拉箭头，点击展开模型列表
右侧两个按钮：新建对话、设置
3.2 左侧会话栏
宽度固定 240px
每条会话以卡片形式展示，显示标题和最后消息时间
鼠标悬停时高亮
底部固定一个新建按钮
3.3 对话主区域
用户消息在右侧，使用蓝紫渐变背景
AI 消息在左侧，使用深色毛玻璃卡片
AI 回复支持流式逐字渲染，末尾带闪烁光标
AI 消息右上角有停止按钮，点击可中断生成
底部固定输入框，支持回车发送，右侧有语音输入图标
3.4 右侧控制面板
默认收起，点击边缘展开
模型切换区：横向排列模型卡片，选中态带渐变边框高亮
参数调节区：温度滑块（0.0 ~ 1.0）、Max Token 滑块（256 ~ 4096）
切换模型时顶部弹出 Toast 提示
4. 配色方案
用途	色值
背景	#0f0f0f
卡片	#1a1a1a
强调色	#6366f1 → #a855f7（渐变蓝紫）
正文文字	#e5e5e5
辅助文字	#888888
毛玻璃效果	backdrop-filter: blur(12px)
5. 核心交互
发送消息

用户输入消息后，通过 SSE 请求发送到后端，AI 回复以流式方式逐字推送到前端，前端逐字渲染到消息气泡中。

切换模型

用户在右侧面板选择新模型，当前正在进行的流式输出不中断。顶部显示 Toast 提示已切换，下一条用户消息将使用新模型。

停止生成

AI 回复过程中，用户点击消息右上角的停止按钮，前端发送停止信号，AI 回复末尾标注已停止。

新建对话

点击新建对话按钮，清空当前会话，聚焦输入框，开始新一轮对话。

面板收起/展开

点击右侧面板边缘，面板宽度收缩为 0，再次点击恢复展开。
