# LLM 智能体对话系统

一个基于 PySide6 的现代化 LLM 对话界面，支持多模型切换、流式输出、参数调节等功能。

## 功能特性

- **多模型切换**：支持 GPT-4、GPT-3.5-Turbo、Claude-3、Llama-3、Qwen-2 等多种模型
- **流式输出**：AI 回复支持逐字渲染，带闪烁光标效果
- **参数调节**：可调节温度 (Temperature) 和最大 Token 数
- **会话管理**：支持多会话切换、新建会话
- **暗色主题**：采用暗色主题 + 毛玻璃质感设计
- **响应式布局**：三栏式布局，右侧控制面板可收起/展开

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python main_window.py
```

## 界面布局

### 顶部导航栏
- 左侧：品牌标识 "LLM Agent"
- 中间：当前模型选择下拉框
- 右侧：新建对话、设置按钮

### 左侧会话栏
- 历史对话列表
- 支持新建会话
- 宽度固定 240px

### 中间对话区
- 消息展示区域
- 用户消息：右对齐，蓝紫渐变背景
- AI 消息：左对齐，深色毛玻璃卡片
- 底部输入框，支持回车发送
- 语音输入按钮

### 右侧控制面板
- 模型切换区：横向排列模型卡片
- 参数调节区：温度滑块、Max Token 滑块
- 默认收起，点击边缘展开

## 核心交互

### 发送消息
用户输入消息后，AI 回复以流式方式逐字推送到前端，前端逐字渲染到消息气泡中。

### 切换模型
用户在右侧面板选择新模型，顶部显示 Toast 提示已切换。

### 停止生成
AI 回复过程中，用户点击消息右上角的停止按钮，可中断生成。

### 新建对话
点击新建对话按钮，清空当前会话，聚焦输入框。

### 面板收起/展开
点击右侧面板边缘，面板宽度收缩为 0，再次点击恢复展开。

## 开发说明

### 添加新模型
在 `main_window.py` 中的 `model_combo` 和 `models` 列表中添加新模型名称。

### 修改样式
所有样式定义在 `styles.py` 中，可以统一修改颜色、字体、间距等。

### 扩展功能
- 接入真实 LLM API
- 实现语音输入
- 添加设置界面
- 支持文件上传
- 实现消息搜索

## 注意事项

- 当前版本为 UI 原型，AI 回复为模拟数据
- 需要 PySide6 6.5.0 或更高版本
- 建议使用 Python 3.8+
